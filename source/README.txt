Seneca homepage system — source
Rebuild:  pip install jinja2 && python3 build.py assets ../
Add a child site: add one entry to PROPS in build.py (5 colour tokens, logo PNG in assets/, photos, copy), add its key to ORDER, and rebuild.
Property order + colours: 1 Niagara = blue #659BD0 · 2 Hickory Stick Golf = green #89B24B · 3 Buffalo Creek = red #BC4033 · 4 Allegany = brown #B77E42.
Note: the Allegany and Hickory Stick logos were recoloured to match their themes; replace with official brand artwork when available.
